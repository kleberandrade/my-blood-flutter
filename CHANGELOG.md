# Changelog

## 1.0.0+9 — 2026-11-17

- Migrated Dart 2.7 / Flutter-era 0.6.0+8 prototype to Flutter 3.50.0 and null-safe Dart 3.14.
- Replaced unconfigured Firebase authentication and obsolete plugin stack with an explicitly labeled, local-only demonstration.
- Added responsive community campaign catalog, combined state/city/blood/search filters, local creation/editing, bookmarks, and bilingual UI with locally drawn circular flags.
- Persisted campaigns, saved IDs and language in a versioned storage record; added retry, visible save failure and confirmed local reset.
- Added sharing preview/copy that never sends messages; fictional facility directory and official educational references.
- Added domain, persistence and interface tests, Web build workflow, current screenshots, privacy and integration documentation.
- Retained original attribution, research reference and MIT grant from the historical README.
